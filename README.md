Cloud layers is a Jarmod I made for Alpha 1.1.2_01, Beta 1.7.3, And Minecraft: Oldschool Edition. This mod adds two additional cloud layers hence the title. The second layer is a 3D layer just like the first and the third is a 2D layer which is just the fast clouds. There is a settings txt file in each zip that will allow u to personalize the mod. This mod could receive updates in the near or far future that consist of bug fixes mainly so if u care that much for it keep ur eyes peeled for updates. M:OE stands for Minecraft: Oldschool Edition.
